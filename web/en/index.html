Your ERP, with nothing to map by hand

There is no separate Plania per system. There is an auto-mapper that recognises how each one names its columns, so the connection sets itself up.

Zureo

Zureo runs in the cloud, so there is no on-premise database to connect to directly. Export stock, sales or customers to Excel or CSV from within Zureo itself, and Plania maps the columns on its own.

Memory

If Memory lets you export to Excel or CSV, that is the fastest start. If you have direct access to its database, Plania connects with nothing more than the connection string.

Tango

Tango installations usually run on a local database. With a read-only user for that database, Plania connects directly — no exports, no middleman.

Bejerman

Same story with Bejerman: if your installation runs locally, you connect directly to its database. Plania still detects the columns even if your install renamed them.

The rest is handled by the auto-mapper: 177 typical column names from these systems plus Odoo, SAP Business One and generic databases — código, artículo, existencia, rubro, cardcode, itemcode, docdate and their variants. If your system uses a name that is not on the list yet, it gets added and keeps working.

Five decisions, with the real number behind each one

Not charts — the five questions a distributor owner asks every week, each one with a real example from the demo dataset.

Overstock → a discount with a real floor

It spots the stock that stopped moving and works out the discount, never below cost plus 8%. Real example: “Lácteos Oro 395” has 584 units sitting for 113 days — UYU 106,183 tied up in that product alone. Across the full dataset, it frees up UYU 1,430,318.

Restocking before you run out

It cross-checks real turnover against each supplier's lead time. Real example: “Bebidas Eco 558” has 6 days of stock left and the supplier takes 8 — UYU 80,607/month of revenue at risk if it is not reordered today. Across the dataset, UYU 1,132,051 is at risk.

Re-pricing what is leaking margin

It finds products selling below their category's margin. Real example: “Lácteos Clásico 736” sells at a 14% margin against a 25% category average — raising the price 14.7% adds UYU 5,765/month. Across the dataset, that is UYU 96,373/month.

Cross-selling by zone

It compares which categories similar businesses buy, zone by zone. Real example: in Punta del Este, only 67% of Almacén-type businesses buy Limpieza products versus 99% across the rest of the dataset — a whole category nobody is offering there.

Winning back customers who stopped buying

It compares each customer's usual buying rhythm against how long it has been since their last order. Real example: “Almacén García” used to buy UYU 207,288 and has gone 52 days without ordering. Across the dataset, UYU 885,661 sits in customers worth calling back.

All five examples come from running Plania's real engines on its demo dataset (synthetic data, not an actual customer) — so you can see the level of detail before connecting your own.
